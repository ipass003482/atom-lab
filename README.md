# ATOM LAB · 原子實驗室

繁體中文賽博風互動化學網站，純 HTML / CSS / JavaScript，不需安裝套件或設定 API 金鑰。包含完整 **118 種元素、1,648 筆物質與 2,078 筆反應**，並可即時查詢 PubChem 與 Rhea。

專案儲存庫：[ipass003482/atom-lab](https://github.com/ipass003482/atom-lab)。網站使用 GitHub Pages，由 `main` 分支根目錄發布至 [ATOM LAB](https://ipass003482.github.io/atom-lab/)。

## 功能與資料規模

| 內容 | 離線收錄 | 用途 |
|---|---:|---|
| 元素 | 118 種 | 中文與英文名稱、原子序、原子質量、分類及週期表 |
| 物質 | 1,648 筆 | 148 筆教學資料＋1,500 筆 PubChem 名稱、分子式與式量記錄 |
| 反應 | 2,078 筆 | 50 組教學範例＋2,028 筆 Rhea 專家策展生化反應 |

- 物質與反應庫可搜尋、分頁，並依分類、來源及物態篩選；同分子式候選由使用者選擇。
- 原子組合可加入、移除、清空；化學式支援巢狀括號、中括號、結晶水、Unicode 下標及明確離子電荷。
- 只輸入反應物可查詢教學反應範例；輸入完整反應式可使用 BigInt 有理數演算法配平，檢查原子與電荷守恆。
- Rhea 反應從目錄或線上結果載入，保留來源名稱與係數並檢查守恆；不會僅憑分子式自動認定特定生化反應。
- 可旋轉、縮放結構示意，已知物態可顯示固、液、氣粒子運動；收錄的反應可顯示放熱、發光、氣泡、沉澱與風險概念特效。
- 支援桌面、平板、手機、鍵盤操作與系統「減少動態效果」設定。支援 WebMCP 的瀏覽器另可使用查詢與配平工具。

## 線上資料庫

在「線上資料庫」分頁選擇來源、輸入查詢，再按「載入實驗台」。

| 來源 | 查詢範例 | 回傳範圍 |
|---|---|---|
| PubChem | `caffeine`、`C2H6O`、`CID 962` | 名稱、分子式、式量及 CID；每次最多 20 筆，更多結果可至來源網站查看 |
| Rhea | `glucose`、`ATP`、`C6H12O6`、`RHEA:10000` | 已核准、已配平、非運輸的生化反應；每頁最多 20 筆，可翻頁 |

英文名稱通常較適合公開資料庫搜尋；部分已收錄中文名稱可轉為 PubChem 查詢。搜尋內容會送至所選資料庫，需要網路。新增記錄只保留在本次開啟的頁面，重新整理後回到離線資料集。

這些資料庫與本網站均**未涵蓋全世界全部物質與反應**。Rhea 泛化參與物、變數聚合物、缺少明確係數或只有結構改變而分子式不變的記錄，可能無法載入目前模型。PubChem 含同位素標記或缺少可靠組成、電荷資料的結果也會標示不支援。

## 放上 GitHub Pages

1. 建立你的 GitHub 儲存庫，例如 `atom-lab`。
2. 將本資料夾**裡面的檔案**上傳至儲存庫根目錄，確認最外層就有 `index.html`。不要只上傳 ZIP。
3. 儲存庫開啟 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 **/(root)**，按 **Save**。
6. 等待 GitHub 完成發布，Pages 設定頁會顯示網站網址。一般專案網址為 `https://你的帳號.github.io/儲存庫名稱/`。

`.nojekyll` 已包含在檔案中，沒有建置步驟。資源使用相對路徑，支援 GitHub Pages 儲存庫子路徑。來源說明與授權註記請一併保留。官方步驟見 [GitHub Pages 發布來源設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 可以試試

| 模式 | 輸入 | 預期結果 |
|---|---|---|
| 化學式探索 | `Ca(OH)2` | Ca 1、O 2、H 2 |
| 化學式探索 | `Fe2(SO4)3` | Fe 2、S 3、O 12 |
| 化學式探索 | `CuSO4·5H2O` | Cu 1、S 1、O 9、H 10 |
| 化學式探索 | `SO4^2-` | 硫酸根的組成與 −2 電荷 |
| 物質庫 | `C2H6O` | 同組成候選，需選擇特定物質 |
| 反應配平 | `H2 + O2` | 已收錄的生成水反應與風險說明 |
| 反應配平 | `Fe + O2 = Fe2O3` | `4 Fe + 3 O2 → 2 Fe2O3` |
| 反應配平 | `C6H12O6 + O2 = CO2 + H2O` | `C6H12O6 + 6 O2 → 6 CO2 + 6 H2O` |
| 反應配平 | `Fe^2+ + Ce^4+ = Fe^3+ + Ce^3+` | 原子與電荷同時守恆 |

完整反應式可用 `→`、`->`、`=>` 或 `=`。手動輸入的原有係數會重新配平；只輸入反應物是依物質種類查詢範例，並非依投料量計算反應。

## 科學與技術範圍

**通用化學式解析與配平不等於任意反應預測。**

- 組成相同不保證物質相同；分子式不能唯一決定同分異構物、立體結構或晶型。畫面會顯示候選與來源名稱。
- 配平只驗證守恆，不判定自發性、速率、產物、混合物危險性或是否爆炸。資料庫記錄也不代表任意混合後就會反應。
- PubChem 擴充記錄未匯入物態、危害或完整三維結構；Rhea 記錄未提供產品物態或危害判定。這些欄位保持未知，不由分子式推測。「未收錄」不代表安全或不反應。
- 有物態資料的教學項目以約 25 °C、1 atm 為參考；超重元素 104–118 標為未知。元素參考物態指巨觀元素物質，並非單一孤立原子。
- 模型是投影式粒子示意，並非量子化學、精確晶胞或分子動力學計算。未知結構只顯示組成，不自動生成假結構；風險特效沒有實際操作步驟或條件數值。
- H 是一個氫原子，H2 才是氫氣分子；由原子描述 H2O 與氫氣、氧氣燃燒是不同概念。
- 解析器上限為每次輸入 1,000 字元、每個化學式合計 1,000,000 個原子（網頁化學式欄限制 500 字元）。點選模式最多 240 顆；模型最多顯示約 120 個抽樣粒子，計算仍保留完整原子數。
- 支援 `Fe^3+`、`SO4^2-`、Unicode 上標電荷與 `e^-`；不接受可能歧義的 `Fe3+`，不支援同位素、變數聚合物、分數佔位或 `(aq)` 等物態後綴。
- 無唯一正整數解、無法守恆、錯字或過大係數會回報錯誤。公開 API 也可能因斷線、限流或逾時無法回應，離線資料仍可使用。

## 本機使用與測試

直接用瀏覽器開啟 `index.html` 可使用離線功能。線上查詢需能連線至 PubChem 與 Rhea；若本機檔案模式受到瀏覽器限制，可改由靜態 HTTP 伺服器開啟。

有 Node.js 時，在此資料夾執行：

```sh
node chem-engine.test.js
node catalog.test.js
```

`chem-engine.test.js` 包含 **92 組引擎測試**，涵蓋 118 種元素、100 種生成的烷類燃燒反應、巢狀括號、水合物、離子反應、大整數與非法輸入。`catalog.test.js` 另行驗證資料集與目錄邏輯，包括來源筆數、化學式、反應守恆、搜尋及候選辨識；這些資料集檢查不計入上述 92 組。
